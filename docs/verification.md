# 検証記録

2026年10月15日。Apple Silicon Mac / macOS 15.8.1で確認。

## 確認済み

| 検証 | 結果 |
| --- | --- |
| 状態遷移の単体検証 | 16項目すべて成功 |
| 消灯要求を除去した退行版 | ふた閉じ・消灯の検証が失敗することを確認 |
| Releaseビルド | 成功、コンパイラ警告なし |
| アドホック署名 | アプリと同梱ヘルパーを署名、deep / strict検証成功 |
| 起動時の実システム設定 | アプリ自身のPreventUserIdleSystemSleepとSleepDisabled=1を確認 |
| 画面の点灯維持 | アプリ自身はPreventUserIdleDisplaySleepを登録していない |
| 外部から設定を解除 | 実際に解除し、起動中のアプリが再適用することを確認 |
| 復元監視の異常終了 | 監視プロセスを強制終了し、再起動を確認 |
| 通常終了 | 元のSleepDisabled=0へ戻り、防止要求が残らないことを確認 |
| アプリ本体の強制終了 | 別プロセスが元のSleepDisabled=0へ戻すことを確認 |
| ネイティブUI | アプリ自身のビューをPNG化して文字・ボタン・配置を目視確認 |
| 配布ZIP | 破損検査とアプリ本体の格納を確認 |

実システムの検証には、すでに導入済みのCapsomnia用固定ヘルパーを使用。
旧版Capsomnia本体は正常終了させ、設定の競合を避けた。
仮のcaffeinateはAntiSleepの防止要求を確認してから終了した。

初回の終了検証で、設定の復元後も終了応答を待ちプロセスが残る問題があった。
終了通知元のイベントループに依存せず、復元と監視停止を確認して終了するよう修正し、
通常終了・強制終了を含む実機検証を再実行して成功した。

画面収録によるOSウィンドウ画像の取得は、画面収録権限がなく失敗した。
そのため、他アプリやデスクトップを取得せず、アプリ自身のビュー描画を検査した。

## 保留・未検証

- **画面を消灯したまま70秒間の処理継続：保留。** 検証途中にタッチパッド操作で画面が点灯した。
  処理の継続だけでは消灯状態の継続を証明できないため、その区間は不採用。
  消灯・点灯イベントも検証するようスクリプトを修正し、ユーザーの指示で試験を最後へ延期した。
- **実際にふたを閉じた状態での処理継続と復帰：未検証。**
  SleepDisabled=1の適用と確認、ふた閉じ時の消灯を要求する状態遷移の単体検証まで実施。
  実際のふた操作を伴う確認は別途必要。
- **新規ヘルパーの管理者認証付きインストール：未実施。** スクリプトの構文、バンドルへの同梱、
  ヘルパーのビルド・署名は確認した。既存ヘルパーが使えたため、管理者設定を書き換える導入試験は行っていない。
- **OSクラッシュ・強制電源断・ログアウト時に全監視プロセスも強制終了する条件：未検証。**
  復元を保証する対象に含めていない。
- **Developer ID署名・Apple公証：なし。** ローカルのアドホック署名ビルド。

## 再現方法

```sh
swift run AntiSleepChecks
zsh scripts/build-app.sh
```

以下は実際に電源設定を変更する検証。
AntiSleepと旧版Capsomniaを終了し、開始時点のSleepDisabled=0を確認してから実行する。
既存の設定を保護するため、開始時点の状態が違う場合は検証を中止する。

```sh
python3 scripts/verify-system.py dist/AntiSleep.app test-results/system-check.json
```

消灯試験は、70秒間キーボード・マウス・タッチパッドに触れずに待てる場合に限り、最後に行う。
途中で点灯した場合は失敗として記録し、消灯試験の成功とは扱わない。

```sh
python3 scripts/verify-system.py dist/AntiSleep.app test-results/screen-off-check.json --screen-off
```

生ログ・画像・JSONはtest-results/に置き、Gitには含めない。
